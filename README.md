# ClipMotive 🎬✨

**Turn your long videos into viral, ready-to-post short clips for TikTok, YouTube Shorts, and Instagram Reels — automatically using AI.**

ClipMotive processes your video, detects the most engaging moments, crops them into 9:16 vertical format, and burns in beautiful, animated captions. No video editing experience or external tools required.

---

## 🚀 Key Features

* **AI Moment Finder:** Automatically detects the best hooks and payoffs in your video.
* **Auto 9:16 Vertical Format:** Crops horizontal videos to portrait orientation with an aesthetic blurred background.
* **Animated Captions:** Adds eye-catching word-by-word subtitles (Pop, Zoom, or Fade animations) burned directly into the video.
* **Topic-Focused Search:** Input specific keywords to guide the AI to find moments discussing those topics.
* **Desktop App:** A simple and clean graphical interface — just drag, click, and process.

---

## 📥 How to Download & Install (Windows)

The application is pre-packaged. You do **not** need to install any additional tools (like Python or FFmpeg).

1. Go to the **[Releases](https://github.com/agung2001/clipmotive/releases)** page of this repository.
2. Download the latest installer file (e.g., `ClipMotive-Setup.exe` or `.msi`).
3. Run the downloaded file and follow the on-screen instructions to complete the installation.
4. Launch **ClipMotive** from your Windows Start Menu.

---

## ⚙️ Initial Setup (One-Time Only)

To power the AI processing, ClipMotive requires two free API keys:

1. **OpenRouter API Key** (used for AI moment detection):
   * Sign up and generate a free key at: [openrouter.ai/keys](https://openrouter.ai/keys)
2. **Groq API Key** (used for high-speed speech-to-text transcription):
   * Sign up and generate a free key at: [console.groq.com/keys](https://console.groq.com/keys)

*Paste these keys into the **Settings** screen in ClipMotive when you run the app for the first time.*

---

## 💻 How to Use

1. **Choose Video:** Click the button to select the video file (`.mp4`) you want to clip from your computer.
2. **Adjust Options (Optional):**
   * **Keywords:** Add specific topics (e.g., *finance, comedy, motivation*) to direct the AI toward those themes.
   * **Language:** Select the language of the video (e.g., English or Indonesian) for maximum subtitle accuracy.
   * **Subtitle Style:** Customize text colors, sizes, and animations.
3. **Start Processing:** Click the **Process** or **Start** button. The app will generate your clips automatically.
4. **Done:** The output clips will be saved in your chosen folder, ready to upload!
